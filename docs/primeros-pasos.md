# Primeros pasos

La primera vez que abres JHX//CORE aparece un **recorrido guiado**: oscurece la pantalla, ilumina cada botón y te explica qué hace. Puedes seguirlo con los botones «continuar» / «atrás», con las flechas y Enter, u **omitirlo** (Esc). Más tarde lo repites desde **Configuración ⚙ → ayuda**.

## Lo mínimo para empezar

1. **Vincular (F5).** Pulsa «iniciar sesión en el navegador» y autoriza el acceso con tu cuenta de Claude. El token se recibe **automáticamente**, sin consolas y sin que se vea en pantalla: va directo a la caja fuerte cifrada. Después creas tu **PIN de 6 números**. Se hace una sola vez. (Si prefieres, elige el modo **manual** y copia el token tú mismo.)
2. **Tu PIN.** Escríbelo directamente con el teclado (sin hacer clic).
3. **Carpeta de trabajo.** Elige dónde va a trabajar Claude (se recuerda en este PC). Si no eliges ninguna, usa «JHXCORE Proyectos» dentro de Descargas.
4. **Iniciar Claude Code (F1 o Enter).** Se verifica tu PIN y se abre el chat.

Desde la próxima vez: **tu PIN + Enter**.

## Los botones

| Botón | Qué hace | Atajo |
|---|---|---|
| **Iniciar Claude Code** | Abre el chat en tu carpeta de trabajo. | F1 / Enter |
| **Restaurar PC** | Crea un punto de restauración de Windows (necesita modo administrador). | F2 |
| **Mis proyectos** | Muestra las carpetas donde ya trabajaste y abre el chat en la que elijas. | F4 |
| **Vincular** | Conecta tu cuenta de Claude y crea tu PIN. | F5 |
| **Actualizar Claude** | Busca una versión nueva de Claude Code; te pregunta antes de instalar. | F6 |
| **Desvincular** | Borra tu token de esta instalación. | F9 |
| **Actualizar JHX//CORE** | Busca una versión nueva del programa (con firma del autor). | — |
| **Reportar un problema** (🏳) | Te explica cómo escribirme y copia los datos de tu versión. | — |
| **Tema** | Cambia el color del programa y del chat. | — |
| **Configuración** ⚙ | Letra del chat, permisos, historial, cambiar PIN, ayuda y restablecer. | — |

Pasa el ratón sobre cualquier botón para ver su descripción.

## En el chat

- Escribe y pulsa Enter. **Shift+Enter** hace un salto de línea.
- Adjunta fotos y archivos con el **+**, pegando con **Ctrl+V** o **arrastrando y soltando**.
- A la izquierda están tus conversaciones anteriores (se guardan en tu equipo).
- Arriba eliges el modelo, el esfuerzo y los **permisos**: qué puede hacer Claude sin preguntarte.
- **Esc** detiene a Claude mientras responde.

## Permisos

| Modo | Qué hace |
|---|---|
| **Preguntar siempre** | Te pide permiso para cada comando o cambio. |
| **Preguntar lo peligroso** | Lo seguro va solo; borrar, formatear, tocar el registro, apagar o instalar te pregunta. |
| **Permitir todo** | No pregunta nada. Úsalo con cuidado. |
